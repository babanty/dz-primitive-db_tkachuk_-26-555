# Primitive DB

Учебная консольная база данных на Python 3.12+.

Приложение поддерживает создание таблиц, типизированные CRUD-операции,
хранение данных в JSON, форматированный вывод, подтверждение удаления
и кэширование выборок.

Проект реализован процедурно, без классов в коде приложения.

## Требования

- Python 3.12+ — при необходимости устанавливается через uv.
- uv.
- Git.

Приложение работает на Windows, Linux и macOS.

## Установка для разработки

Из корня репозитория:

```bash
uv sync
```

## Запуск

```bash
uv run database
```

Альтернативные точки входа:

```bash
uv run project
uv run python -m primitive_db.main
```

## Управление таблицами

```text
create_table users name:str age:int is_active:bool
list_tables
info users
drop_table users
```

Поддерживаются типы:

| Тип | Пример |
| --- | --- |
| `int` | `28`, `-10` |
| `str` | `"Sergei"`, `"Иван Петров"` |
| `bool` | `true`, `false` |

Все поля обязательны.

Имена таблиц и столбцов — ASCII-идентификаторы: буквы, цифры
и подчёркивание; имя не может начинаться с цифры.

Столбец `ID:int` добавляется первым автоматически.
Допустимо явно указать `ID:int` при создании схемы, но передавать его
значение при вставке или изменять через `update` нельзя.

## CRUD-операции

### Создание записи

```text
insert into users values ("Sergei", 28, true)
insert into users values ("Иван, Петров", 35, false)
```

Значения передаются в порядке объявления столбцов, без ID.

ID вычисляется как максимальный ID среди текущих записей плюс один.
В пустой таблице первая запись получает ID=1.
После удаления максимального ID его значение может использоваться снова.

### Чтение

```text
select from users
select from users where age = 28
select from users where name = "Иван, Петров"
```

Результат выводится с помощью PrettyTable.

### Обновление

```text
update users set age = 29 where name = "Sergei"
update users set age = 30, is_active = false where ID = 1
```

### Удаление

```text
delete from users where ID = 1
```

## Декораторы и кэширование

- `handle_db_errors` централизованно обрабатывает ожидаемые ошибки.
- `confirm_action` запрашивает подтверждение опасных операций.
- `log_time` измеряет время `insert` и `select` через `time.monotonic()`.
- `create_cacher` реализует ограниченный кэш в замыкании.

Ключ кэша выборки включает содержимое данных и условие.
Изменение таблицы приводит к использованию другого ключа:
устаревший результат не возвращается.

Результаты копируются, чтобы изменение возвращённой записи
не повреждало кэш. Максимальный размер — 128 запросов.
Кэш существует только в памяти текущего процесса.

Кэширование не устраняет чтение JSON и сериализацию ключа:
оно позволяет повторно использовать результат фильтрации.

## Архитектура

```text
src/primitive_db/
├── __init__.py
├── constants.py   # константы и справка
├── core.py        # таблицы, валидация и CRUD
├── decorators.py  # ошибки, подтверждение, время и кэш
├── engine.py      # консольный цикл и выполнение команд
├── main.py        # точка входа
├── parser.py      # разбор команд и значений
└── utils.py       # файловая система и JSON

tests/             # модульные и интеграционные тесты
```

## Сборка и установка пакета

Следующие команды приведены для Bash/Git Bash:

```bash
uv build
uvx twine check dist/*
uv tool install --force dist/*.whl
```

Перед установкой убедитесь, что в `dist/` находится wheel только
одной версии проекта.

Если директория инструментов отсутствует в PATH:

```bash
uv tool update-shell
```

После обновления PATH и перезапуска терминала:

```bash
database
```

Также доступна команда `project`.

Проверка через `twine check` анализирует метаданные локально.
Публикация на PyPI для запуска приложения не требуется.
